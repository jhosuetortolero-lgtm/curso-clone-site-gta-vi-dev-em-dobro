# Clone Site GTA VI

Réplica de estudo da página de anúncio de Grand Theft Auto VI, feita como exercício de HTML, CSS e JavaScript com foco em animações de rolagem.

> Projeto educacional, sem fins comerciais. GTA VI e as marcas relacionadas pertencem à Rockstar Games / Take-Two Interactive.

**Demo:** https://jhosuetortolero-lgtm.github.io/curso-clone-site-gta-vi-dev-em-dobro/

## Funcionalidades

- Seção de capa com vídeo de fundo em autoplay
- Animações de entrada e efeitos de rolagem com GSAP e ScrollTrigger
- Layout responsivo para desktop e mobile

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP + ScrollTrigger

## Como executar

```bash
git clone https://github.com/jhosuetortolero-lgtm/curso-clone-site-gta-vi-dev-em-dobro.git
cd curso-clone-site-gta-vi-dev-em-dobro
```

Depois, abra o `index.html` no navegador ou sirva a pasta com uma extensão como o Live Server.
